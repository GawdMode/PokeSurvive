# Known Issues — Pre-Alpha RC

This list is intentionally conservative. Additional issues are expected to be
found during public alpha testing.

- Save compatibility between major development/alpha revisions is not guaranteed.
- Adventure and camping event variety/weighting is still being tuned and some
  dialogue may repeat more often than desired.
- Event dialogue is generated from many dynamic combinations; occasional awkward
  grammar or presentation may remain.
- Randomized balance can produce unusually easy or difficult encounters.
- The full game has not yet received exhaustive end-to-end regression testing
  with every combination of run options.
- Public alpha testers should prefer fresh runs when reporting reproducible bugs.
