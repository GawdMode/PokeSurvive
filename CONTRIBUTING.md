# Contributing to PokeSurvive

PokeSurvive is currently in public alpha. The most useful contribution right now is testing and clear bug reporting.

## Reporting bugs

Please use the GitHub Issues bug-report form and include:

- Your PokeSurvive version.
- Your Gen1Recomp version.
- Whether the run was started fresh on that version.
- What happened and what you expected.
- Reproduction steps, if known.
- Screenshots or video when they help illustrate the problem.

Balance feedback, strange event behavior, dialogue errors, and reproducible gameplay issues are all useful during alpha.

## Source contributions

Code contributions may be considered later as the project matures. For now, please open an Issue before preparing a substantial code change so work is not duplicated.
